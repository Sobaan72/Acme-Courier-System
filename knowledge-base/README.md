# Knowledge base

`acme_knowledge_base.md` holds the company's policies and FAQs (service area, tiers, pricing zones, cutoff times,
size limits, cancellation, proof of delivery, payments, privacy, escalation and more). It's stored in
`knowledge_documents` and loaded into the WhatsApp agent's prompt, so answers come from the company's
own rules rather than the model's general knowledge.

`sample_call_transcripts.md` contains realistic (fictional) intake calls used to design and test the voice agent.
